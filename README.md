# Прогнозирование финансовых временных рядов с помощью вариационного автоэнкодера

Этот проект представляет собой систему вероятностного моделирования фондового рынка. В отличие от классических алгоритмов, которые пытаются угадать точную цену актива на завтра, этот проект работает по принципу метеорологического прогноза. Он не выдает точечных предсказаний, а изучает фундаментальный характер рынка и оценивает плотность распределения будущих доходностей. Результатом работы является генерация множества математически обоснованных рыночных сценариев, что позволяет оценивать вероятности движения капитала и возможные риски.

В основе проекта лежит архитектура вариационного автоэнкодера и метод симуляций Монте-Карло. По своей сути, вариационный автоэнкодер - это тип генеративной нейронной сети, которая учится сжимать сложные данные в упрощенное вероятностное представление, а затем разворачивать их обратно. Это позволяет алгоритму не просто слепо копировать исторические графики, а улавливать саму математическую суть процессов и генерировать абсолютно новые, ранее не существовавшие последовательности с реалистичными характеристиками.

## Данные и предобработка

Для обучения модели используются исторические данные индекса S&P 500, которые загружаются через Yahoo Finance. Модель анализирует не абсолютные цены, масштаб которых может сбивать алгоритмы с толку, а два более универсальных показателя. Первый показатель - логарифмическая доходность, которая выражает ежедневное изменение цены в процентах и позволяет нейросети сфокусироваться на динамике. Второй показатель - объем торгов, помогающий алгоритму понять силу и значимость движения цены.

Данные разделены на два периода. Десять лет истории с 2015 по 2025 год используются для обучения модели пониманию различных рыночных циклов, включая кризисы и периоды бурного роста. Отрезок с мая 2025 по май 2026 года выделен для независимого тестирования. Вся история нарезается на скользящие окна по 20 торговых дней, поэтому для формирования выводов о текущем состоянии рынка нейросеть всегда опирается на один прошедший торговый месяц.

## Архитектура модели

Нейронная сеть состоит из двух главных модулей, которые работают в паре и используют слои нейросетей с долгой краткосрочной памятью для понимания правильной последовательности событий во времени.

### Модель распределения

Задача энкодера - взять рыночный график за последние 20 дней и сжать его до 16 абстрактных параметров скрытого пространства. При этом он выдает не жесткие цифры, а задает диапазоны через математическое ожидание и дисперсию. Это позволяет описать текущее состояние рынка, например степень волатильности или силу текущего тренда, в виде вероятностей.

### Модель генерации

Декодер делает обратную работу. Он берет случайную точку из сформированного скрытого пространства и пытается развернуть ее обратно в реалистичный 20-дневный рыночный график.

## Функция потерь и вариационный вывод

Обучение сети происходит через оптимизацию функции потерь, которая заставляет модель делать две вещи одновременно. Первая часть функции рассчитывает среднеквадратичную ошибку реконструкции, требуя от декодера генерировать графики, максимально похожие на оригинальные данные. Вторая часть использует дивергенцию Кульбака-Лейблера - статистическую метрику, измеряющую отличие одного вероятностного распределения от другого. В этом проекте она выступает в роли регуляризатора и жестко штрафует модель, если параметры скрытого пространства сильно отклоняются от стандартного нормального распределения. Без этого штрафа нейросеть просто зазубрила бы исторические данные и не смогла бы генерировать ничего нового. Данная метрика делает скрытое пространство гладким и непрерывным, позволяя брать из него случайные значения и получать абсолютно новые, но математически достоверные варианты рыночных сценариев.

## Оценка результатов и метод Монте-Карло

Качество такой вероятностной модели невозможно оценить простым сравнением предсказанного значения с фактическим. Для проверки работоспособности алгоритма применяются два подхода. Первый заключается в оценке плотности распределения. На тестовой выборке модель генерирует новые данные, после чего строится график ядерной оценки плотности для реальных и синтезированных доходностей. Их полное совпадение доказывает, что нейросеть успешно выучила пульс рынка и генерирует реалистичные амплитуды колебаний.

Второй подход переводит абстрактные вероятности в практическую финансовую плоскость с помощью симуляции Монте-Карло. Это класс алгоритмов, основанных на многократном прогоне случайных сценариев для вычисления вероятностей сложных процессов. Поскольку нейросеть предсказывает распределение вероятностей, единичный прогноз не имеет смысла. Для оценки будущего капитала модель анализирует последние 20 дней реального рынка, определяет текущие параметры распределения и делает из него 1000 независимых случайных выборок. Каждая выборка прогоняется через декодер, создавая 1000 равновероятных альтернативных вариантов рынка на следующий месяц.

Затем программа симулирует инвестирование стартовых 10000 долларов в каждый из этих сценариев. На выходе получается конкретная статистика: математическое ожидание прибыли, вероятность остаться в плюсе, а также точная оценка хвостовых рисков и наихудшего возможного сценария просадки.

## Структура проекта

Структура проекта разделена на несколько файлов, каждый из которых отвечает за свой этап работы. Архитектура сети, включающая классы энкодера, декодера и саму функцию потерь, описана в файле models/vae_model.py. Загрузка данных, математический расчет лог-доходностей и формирование скользящих временных окон вынесены в отдельный модуль utils/data_loader.py. За процесс обучения модели на исторических данных отвечает скрипт train.py, который по завершении работы автоматически сохраняет веса и параметры масштабирования. Тестирование, построение графиков плотности и запуск симуляции Монте-Карло выполняются через скрипт evaluate.py. Готовые веса обученной модели и параметры нормализации сохраняются в файлы models/vae_trading.pth и models/scaler.pkl соответственно, что позволяет пользователям запускать симуляции рынка сразу, без необходимости тратить время на повторное обучение нейросети.
